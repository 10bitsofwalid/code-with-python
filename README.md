# Code with Python

Collection of Python practice scripts covering core language fundamentals through object-oriented programming. Written while learning Python from scratch — variables, operators, data structures, file I/O, and OOP basics.

## Contents

### `practice stage/`
Day-by-day and standalone practice files covering:
- Variables, data types, arithmetic and comparison operators
- Strings, lists, and list methods (`append`, `sort`, `reverse`, `insert`, `remove`)
- User input and basic problem solving (sum, average, area calculations)
- File I/O — reading, writing, and appending to files (`open`, `read`, `readline`, `write`), including file mode reference (`r`, `w`, `x`, `a`, `b`, `t`, `+`)
- Small exercises combining file I/O with string search/replace logic

### `oops in python/`
Early object-oriented programming exercises in Python.

## Getting Started

Requires Python 3.

```bash
git clone https://github.com/10bitsofwalid/code-with-python.git
cd code-with-python
python "practice stage/day1.py"
```

Each script is standalone — run any file directly to see its output.

## Purpose

This repo tracks day-to-day progress while learning Python, kept public as a running log and personal reference.
